# Local Coding Models (LCM) install page

The GitHub Pages site is the installable LCM PWA. Install it from [https://vflzx.github.io/local-coding-models-install/](https://vflzx.github.io/local-coding-models-install/) using Edge or Chrome's **Install app** / **Install page as app** menu. Download the [LCM Windows companion ZIP](https://vflzx.github.io/local-coding-models-install/downloads/LCM-2.6.0-Windows.zip) from the prominent link in the app.

The **Get LCM** download in the app is a Windows source ZIP. Extract it, install Python and Ollama, download a local Ollama model, then run `run.bat`. The companion launches this PWA with a per-computer local port setting and serves the AI and project APIs on loopback. Keep the companion running to use chat, project files, or commands.
